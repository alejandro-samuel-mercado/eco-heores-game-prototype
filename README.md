## 📖 Descripción / Historia  
**Eco Heroes** *(Prototipo)* es un **juego multijugador de mundo abierto** en el que cada jugador asume el rol de un **Eco-Héroe**.  

Explora una **isla dividida en bosques, ríos y playas** 🏝️, colaborando con otros jugadores para resolver **problemas ambientales, sociales y emocionales**.  
Con cada desafío superado, obtendrás **nuevas habilidades** que te permitirán afrontar tareas cada vez más complejas y exigentes.  

---

## 🎯 Objetivos y Misiones  
- 👥 **Trabajar en equipo** para ayudar a los habitantes y animales de la isla.  
- 🌱 **Resolver** problemas ambientales, sociales y emocionales.  
- 🎮 **Participar** en minijuegos didácticos que enseñan:  
  - Ecología  
  - Empatía  
  - Habilidades sociales  

---

## 🎮 Controles  

| Tecla / Botón | Acción |
|---------------|--------|
| ⬆️ Up         | Avanzar |
| ⬇️ Down       | Retroceder |
| ➡️ Right      | Mover derecha |
| ⬅️ Left       | Mover izquierda |
